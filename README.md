# MultiDash UI

**MultiDash UI** is a premium, high-performance command center designed to monitor, analyze, and manage multiple business domains from a single, unified interface. Inspired by top-tier enterprise SaaS platforms, it delivers a sleek dark-mode aesthetic with hardware-accelerated 60fps animations.

## 🚀 Core Value Proposition
Instead of fragmented admin panels, MultiDash acts as the central nervous system for your digital ecosystem. It brings together E-Commerce, Healthcare, Streaming, AI services, and Corporate Banking into one seamless, cross-domain intelligence platform.

## ✨ Key Features

* **Premium Dark Mode Aesthetic:** Designed with deep slate backgrounds, subtle glassmorphism, and vibrant radial gradients to highlight critical data.
* **Fluid 60fps Animations:** Powered by Framer Motion, featuring spring-animated sidebars, smooth page transitions, and interactive micro-interactions that never compromise performance.
* **Advanced Data Visualization:** Interactive `recharts` implementations including stacked revenue bars, dual-line audience insight graphs, and animated progress trackers.
* **Global Command Palette:** A native-feeling `⌘K` (or `Ctrl+K`) search interface for instant navigation and action triggering across the entire platform.
* **MultiDash AI Assistant:** A persistent, floating AI node that maintains state across page navigations, offering contextual cross-domain insights and automated reporting.

## 🏢 Domain Modules

1. **Dashboard:** The central hub featuring cross-domain intelligence, system health monitoring, and aggregated revenue tracking.
2. **E-Commerce:** Live order feeds, conversion metrics, and cart abandonment analytics.
3. **Healthcare:** Real-time patient heartbeat visualizations, health scores, and medical appointment timelines.
4. **Streaming:** Concurrent viewer tracking, trending content carousels, and watch-time analytics.
5. **AI Agent:** A futuristic neural node network visualizing live agent processing tasks and activity streams.
6. **Banking:** Corporate financial health monitoring, encrypted transaction histories, and balance charts.

## 🛠 Tech Stack

* **Framework:** React 18 (Vite)
* **Language:** TypeScript
* **Styling:** Tailwind CSS + `clsx` + `tailwind-merge`
* **Animations:** Framer Motion
* **Charts:** Recharts
* **State Management:** Zustand
* **Icons:** Lucide React

## 📦 Getting Started

```bash
# Install dependencies
npm install

# Start the development server

```
